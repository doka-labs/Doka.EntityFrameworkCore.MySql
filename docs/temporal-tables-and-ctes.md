# Temporal Tables and Common Table Expressions

The original combined guide has been split by feature ownership:

- [Temporal Tables](temporal-tables.md) covers configuration, query operators,
  migrations, reverse engineering, application-time periods, and bitemporal
  storage.
- [Common Table Expressions](ctes.md) covers recursive and non-recursive query
  roots, composability, parameterization, and engine-specific data-modification
  boundaries.

This compatibility page keeps existing public links valid. The two linked
documents are the canonical feature contracts.
