# CRUD Operations

Demonstrates a complete entity lifecycle with filtered reads, deterministic
ordering, pagination, updates, and deletes.

```bash
dotnet run --project examples/CrudOperations/CrudOperations.csproj
```

The project currently uses the repository's default MySQL 8.4 endpoint. The
[shared example configuration](../README.md) documents the supported local
database targets used by the feature-focused examples.
